테밀리(Temily) 데이터 삭제 요청

개발자: 테밀리 운영팀

1. 데이터 삭제 요청 방법

테밀리(Temily) 사용자는 아래의 방법으로 본인의 데이터 삭제를 요청할 수 있습니다.

방법 1: 앱 내에서 직접 삭제

1 테밀리 앱을 실행합니다.
2 하단 탭의 설정으로 이동합니다.
3 회원 탈퇴(데이터 삭제) 버튼을 선택합니다.
4 안내 사항을 확인하고 삭제를 진행합니다.

※ 클럽 운영자(owner) 권한으로 클럽을 개설한 경우, 탈퇴 전 다른 관리자에게 권한을 위임하거나 해당 클럽을 먼저 해체해야 합니다.

방법 2: 이메일을 통한 삭제 요청

앱을 삭제했거나 앱에 접근할 수 없는 경우, 아래 이메일로 데이터 삭제를 요청할 수 있습니다.

이메일: jeonbw@zlgoon.co.kr

제목: [데이터 삭제 요청] 테밀리

본문에 포함할 내용:

  • 앱 내 닉네임 (있는 경우)
  • 소속 클럽 이름
  • 사용 기기 정보 (기기 모델명, OS 버전)
  • 가입 시 사용한 소셜 로그인 이메일 (도입 후)

이메일을 통한 삭제 요청은 본인 확인 후 7영업일 이내에 처리됩니다.

2. 삭제되는 데이터

삭제 요청 시 다음 데이터가 삭제됩니다.

구분 데이터 종류 삭제 여부
계정 사용자 계정 정보(익명 ID, 닉네임) 즉시 삭제
프로필 프로필 이미지, 연락처, 등급 정보 즉시 삭제
클럽 활동 참석 투표, 출석 기록 30일 이내 삭제
로그 서비스 이용 기록, 접속 로그 6개월 이내 자동 파기

주의: 한 번 삭제된 데이터는 복구할 수 없습니다. 탈퇴 전 필요한 기록은 별도로 보관해 주세요. 다른 회원이 참여한 일정·클럽 기록에서 귀하의 활동은 익명화 처리되어 클럽 통계에는 반영될 수 있습니다.

3. 법령에 따라 보관되는 데이터

다음 데이터는 관련 법령에 따라 일정 기간 보관 후 자동 파기됩니다.

  • 서비스 이용 기록: 통신비밀보호법에 따라 3개월 보관
  • 부정 이용 기록: 부정 이용 방지 목적으로 1년 보관

4. 문의 및 이의 제기

데이터 삭제 처리에 대한 이의가 있거나 추가 문의 사항이 있으시면 아래 연락처로 문의해 주세요.
