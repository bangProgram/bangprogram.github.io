1. 삭제 방법

너에게 닿기를은 회원가입 없이 익명 계정으로 이용합니다. 아래 방법으로 언제든지 내 기록을 지울 수 있습니다.

방법 1: 서비스에서 직접 지우기

1서비스를 이용하던 같은 브라우저에서 너에게 닿기를을 엽니다.
2화면 왼쪽 위 내 바다를 누릅니다.
3나 탭에서 내 기록 지우기를 누릅니다.
4안내를 확인하고 한 번 더 누르면 바로 지워집니다.

방법 2: 이메일로 요청하기

브라우저의 사이트 데이터를 지웠거나 기기를 바꿔 서비스에서 지울 수 없을 때는 이메일로 요청해 주세요.

2. 삭제되는 데이터

데이터 처리
익명 계정, 닉네임, 이용 규칙 동의 기록 즉시 삭제
받은 편지 기록, 앨범, 항해일지 즉시 삭제
아직 바다를 떠다니는 내 편지·유리병·소원 바다에서 거둬들여 즉시 삭제
