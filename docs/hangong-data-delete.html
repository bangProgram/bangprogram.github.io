1. 데이터 삭제 요청 방법

한손공부(HanGong) 사용자는 아래의 방법으로 본인의 데이터 삭제를 요청할 수 있습니다.

방법 1: 앱 내에서 직접 삭제

1 한손공부 앱을 실행합니다.
2 하단 탭의 설정으로 이동합니다.
3 계정 > 회원 탈퇴 메뉴를 선택합니다.
4 안내 사항을 확인하고 삭제를 진행합니다.

회원 탈퇴 시 Supabase Edge Function을 통해 계정과 모든 학습 데이터가 즉시 영구 삭제됩니다.

방법 2: 이메일을 통한 삭제 요청

앱을 삭제했거나 앱에 접근할 수 없는 경우, 아래 이메일로 데이터 삭제를 요청할 수 있습니다.

이메일: pepe.dev222@gmail.com

제목: [데이터 삭제 요청] 한손공부

본문에 포함할 내용:

  • 가입 시 사용한 이메일 주소
  • 사용 기기 정보 (기기 모델명, OS 버전)
  • 마지막 사용 시기 (대략적인 날짜)

이메일을 통한 삭제 요청은 본인 확인 후 7영업일 이내에 처리됩니다.

방법 3: 비로그인 사용자의 데이터 삭제

한손공부는 로그인 없이도 사용 가능하며, 비로그인 사용자의 학습 데이터는 사용자 기기의 localStorage에만 저장됩니다. 다음의 방법으로 데이터를 삭제할 수 있습니다.

  • 앱 내 설정 > 데이터 초기화 메뉴 사용
  • iOS: 설정 > 일반 > 저장 공간 > 한손공부 > 앱 제거
  • Android: 설정 > 앱 > 한손공부 > 저장 공간 > 데이터 삭제

2. 삭제되는 데이터

삭제 요청 시 다음 데이터가 삭제됩니다.

구분 데이터 종류 삭제 여부
계정 이메일 주소, 사용자 ID 즉시 삭제
학습 데이터 카드별 SRS 진행도, 정답률, 마스터 여부 즉시 삭제
통계 스트릭, XP, 레벨, 일일 활동, 학습 히스토리 즉시 삭제
게이미피케이션 획득 뱃지, 성장 단계 즉시 삭제
학습 세션 학습 세션 기록, 일일 학습량 즉시 삭제
로그 서비스 이용 기록, 접속 로그 6개월 이내 자동 파기

주의: 한 번 삭제된 데이터는 복구할 수 없습니다. 탈퇴 전 학습 기록을 보관하고 싶으신 경우 별도로 백업해 주세요.

다음 데이터는 관련 법령에 따라 일정 기간 보관 후 자동 파기됩니다.

  • 서비스 이용 기록: 통신비밀보호법에 따라 3개월 보관
  • 부정 이용 기록: 부정 이용 방지 목적으로 1년 보관
