쿠피(Coupy) 데이터 삭제 안내

시행일자: 2026년 4월 27일

쿠피는 회원가입 없이 이용하는 앱이며, 사용자가 등록한 모든 쿠폰 정보 및 이미지는 사용자 기기 내부 저장소에만 보관됩니다. 외부 서버에는 어떠한 개인정보도 저장되지 않습니다.

핵심 요약: 쿠피는 사용자의 데이터를 외부 서버에 저장하지 않습니다. 따라서 별도의 삭제 요청 절차 없이 아래 방법으로 데이터를 즉시 삭제할 수 있습니다.

1. 앱 내 개별 쿠폰 삭제

  1. 쿠피 앱 실행
  2. 홈 화면에서 삭제할 쿠폰 선택
  3. 상세 화면 우측 상단 메뉴 → "삭제"

2. 만료 쿠폰 일괄 정리

  1. 쿠피 앱 실행 → 좌측 상단 메뉴(☰) → "설정"
  2. "데이터" 그룹의 "만료 쿠폰 정리" 선택
  3. 사용 후 30일 경과 이미지 / 60일 경과 기록이 자동으로 삭제됩니다.

3. 모든 데이터 일괄 삭제 (앱 제거)

  1. Android 설정 → 앱 → 쿠피
  2. "저장공간 및 캐시" → "저장공간 지우기" (앱 데이터만 삭제)
  3. 또는 "제거"를 눌러 앱 자체를 삭제 (모든 데이터 영구 삭제)
앱을 제거하거나 저장공간을 지우면 모든 쿠폰 정보, 이미지, 알림 설정이 복구 불가능하게 영구 삭제됩니다. 외부 백업이 없으므로 삭제 전 필요한 정보를 미리 보관해 주시기 바랍니다.

4. 광고 식별자 재설정

Google AdMob이 자동 수집하는 광고 식별자(GAID)는 앱과 무관하게 Android 시스템에서 직접 재설정할 수 있습니다.

  1. Android 설정 → Google → 광고
  2. "광고 ID 재설정" 또는 "광고 ID 삭제" 선택
